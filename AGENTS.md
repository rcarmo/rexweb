# Repository instructions

- Keep changes focused. Follow [SPEC.md](SPEC.md). The Rust service owns PTYs and layouts; browser state owns presentation, selection and the last consumed output offset.
- Build from the root Cargo package with [Oak Oil](https://github.com/oakoliver/oak-oil) via the Makefile. Keep one shared target directory, disable incremental compilation and use the bounded Oak Oil cache. Do not restore the Go service or the Go parity bridge to this branch. Keep `main` and published release tags and assets unchanged.
- Keep the foreground service in one process. Follow Rust ownership and async I/O conventions; bound reads, writes and queues, clean up on disconnect, and preserve shell and session lifetime. Do not introduce Docker daemon access.
- Run shells with the required Linux sandbox, a workspace outside the account home and an explicit environment. Fail closed if the sandbox cannot be applied. Keep the native Unix socket private.
- Keep browser operations allowlisted and preserve authentication, Host and Origin checks, upload confinement and paste sanitisation. Reconnect offsets must advance on parser consumption, not receipt. Do not replay terminal input or mutations or log terminal data, credentials or tickets.
- Keep native TCP opt-in. Non-loopback access requires explicit `-allow-anonymous`; prefer SSH forwarding. Check native changes against the official reference server's versioned `/api/help` and `/llms.txt`. Use disposable workspaces outside the account home.
- Use Bun and the existing webterm TypeScript components, including the Ghostty renderer, font assets, terminal widget and one shared mobile input helper. Run `bun install --frozen-lockfile`, retain the lockfile and document the source pins and local changes in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Keep upstream notices and font licences with their assets.
- Run `make check` before handoff and `make smoke` for service, workspace API or terminal protocol changes. Use `make build` for the static binary and the browser targets for changes to renderer, input or viewer lifecycle. See [CONTRIBUTING.md](CONTRIBUTING.md).
